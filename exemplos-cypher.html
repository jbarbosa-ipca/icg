Exemplos de Cypher

Neste guia vamos praticar as cláusulas Cypher com exemplos:

  1. Criar, consultar, contar e remover um nó
  2. Criar um pequeno modelo de vendas (clientes, vendedores e produtos)
  3. Consultas simples sobre o modelo
  4. Consultas que percorrem relações
  5. Desafio e respetivas soluções

Clica num bloco de código para o copiar para o editor e depois carrega em ▶ (ou Ctrl+Enter) para o executar.

Exemplos: um nó

Criar um nó:

CREATE ({Nome: "Pedro"})

Consultar o nó criado (três formas equivalentes):

MATCH (n {Nome: "Pedro"}) RETURN n
MATCH (n WHERE n.Nome = "Pedro") RETURN n
MATCH (n) WHERE n.Nome = "Pedro" RETURN n

Quantos nós temos:

MATCH (n) RETURN COUNT(n) AS count

Remover um nó:

MATCH (n {Nome: "Pedro"}) DELETE n

Remover tudo (com relações):

MATCH (n) DETACH DELETE n

Exemplos: criar nós e relações

Executa este bloco uma única vez (é uma só query). Se o executares de novo, os nós ficam duplicados — nesse caso limpa a base de dados com MATCH (n) DETACH DELETE n e volta a criar.

CREATE (c1:Cliente{Nome: "Maria", Id: 1})
CREATE (c2:Cliente{Nome: "João", Id: 2})
CREATE (c3:Cliente{Nome: "Cris", Id: 3})
CREATE (v1:Vendedor{Nome: "Matias", Id: 1})
CREATE (v2:Vendedor{Nome: "Julieta", Id: 2})
CREATE (p1:Produto{Nome: "Sapato", Id: 1})
CREATE (p2:Produto{Nome: "Camisa", Id: 2})
CREATE (p3:Produto{Nome: "Bolsa", Id: 3})
CREATE (c1)-[r1:COMPROU {Quantidade: 2}]->(p1)
CREATE (c1)-[r2:COMPROU {Quantidade: 2}]->(p2)
CREATE (c2)-[r3:COMPROU {Quantidade: 2}]->(p1)
CREATE (c3)-[r4:COMPROU {Quantidade: 2}]->(p1)
CREATE (c3)-[r5:COMPROU {Quantidade: 2}]->(p2)
CREATE (c3)-[r6:COMPROU {Quantidade: 2}]->(p3)
CREATE (v1)-[r7:VENDEU_PARA]->(c1)
CREATE (v1)-[r8:VENDEU_PARA]->(c3)
CREATE (v2)-[r9:VENDEU_PARA]->(c2)

Ver o grafo completo:

MATCH (n) RETURN n

Exemplos: consultas simples

Quantos produtos temos?

MATCH (n:Produto) RETURN COUNT(n) AS `Total de Produtos`

Quantos clientes temos?

MATCH (n:Cliente) RETURN COUNT(n) AS NumClientes

Quem são os nossos clientes?

MATCH (n:Cliente) RETURN n

Exemplos: consultas com relações

Quais são os produtos que o cliente com o Id = 1 comprou?

MATCH (c:Cliente {Id: 1}), (p:Produto) RETURN *

Quem é que comprou a camisa?

MATCH (c)-[:COMPROU]->(p:Produto {Nome: "Camisa"}) RETURN c

Quais são os produtos mais vendidos?

MATCH (c)-[r:COMPROU]->(p) RETURN p.Nome ORDER BY r.Quantidade DESC LIMIT 1

Desafio

Tenta escrever a query para cada pergunta antes de avançar para as soluções.

Qual é o vendedor com mais clientes?

Qual o vendedor que vendeu mais produtos?

Qual é o outro produto que devemos oferecer ao João?

Soluções

Qual é o vendedor com mais clientes?

MATCH (v)-[:VENDEU_PARA]->(cliente)
RETURN v.Nome AS Nome_Vendedor, count(v.Nome) AS Total_Clientes
ORDER BY Total_Clientes DESC LIMIT 1

Qual o vendedor que vendeu mais produtos?

MATCH (vendedor:Vendedor)-[:VENDEU_PARA]->()-[c:COMPROU]->()
RETURN vendedor.Nome AS Nome_Vendedor, SUM(c.Quantidade) AS Produtos_Vendidos
ORDER BY Produtos_Vendidos DESC LIMIT 1

Qual é o outro produto que devemos oferecer ao João?

MATCH (:Cliente{Nome:"João"})-[:COMPROU]->(mesmos_produtos)<-[:COMPROU]-(clientes)-[:COMPROU]->(produtos_diferentes)
RETURN produtos_diferentes.Nome
